# Room 13 — Barbershop Website

Адаптивный сайт-визитка для барбершопа **Room 13**.

Проект показывает практические навыки frontend-разработки: семантическая HTML-разметка, адаптивный CSS и интерактивность на чистом JavaScript.

## Возможности

- адаптивная mobile-first верстка;
- современный минималистичный интерфейс;
- галерея с lightbox-просмотром;
- плавные анимации появления блоков;
- структурированная файловая организация;
- интерактивные элементы без сторонних frontend-фреймворков.

## Технологии

`HTML5` · `CSS3` · `Flexbox` · `CSS Grid` · `JavaScript` · `Intersection Observer API`

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server
```
